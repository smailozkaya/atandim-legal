# Atandım — Yasal Metinler

Bu depo yalnızca **Atandım** mobil uygulamasının herkese açık hukuki
metinlerini barındırır:

- [Gizlilik Politikası ve KVKK Aydınlatma Metni](gizlilik.html)
- [Kullanım Koşulları](kullanim-kosullari.html)

Sayfalar GitHub Pages ile yayınlanır. Google Play mağaza kaydı, gizlilik
politikası için herkese açık bir URL zorunlu tuttuğu için bu depo gerekli.

Metinler uygulamanın kaynak deposunda tek bir yerden üretilir
(`src/data/legal.ts` → `npm run legal:build`); buradaki dosyalar elle
düzenlenmemelidir, aksi hâlde uygulama içindeki metinle web sürümü ayrışır.

Uygulama kaynak kodu bu depoda **değildir**.
